How the application works

1. PUSHSave the current version onto the undo stack.
2. POPUndo removes the latest saved state and restores the previous one.
3. REDOThe redo stack stores undone states so they can be restored.

Why a stack?

A stack follows LIFO (Last In, First Out). The latest edit is normally the first edit a user wants to reverse, so a stack makes the history operation natural and efficient.
