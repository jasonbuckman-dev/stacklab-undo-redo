How the application works

1. PUSH Save the previous version onto the undo stack.
2. POP Remove the latest saved state and restore it.
3. REDO Store undone versions so they can be restored.

Why a stack?

A stack follows LIFO: Last In, First Out. The most recent edit is often the first edit a user wants to reverse. The push and pop operations make this history management straightforward and efficient.
